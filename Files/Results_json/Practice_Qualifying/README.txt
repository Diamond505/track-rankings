# Practice and Qualifying Sessions

This folder should contain practice and qualifying session files.

File naming patterns:
- YYMMDD_HHMMSS_FP.json   ← Free Practice
- YYMMDD_HHMMSS_FP1.json  ← Practice 1
- YYMMDD_HHMMSS_FP2.json  ← Practice 2
- YYMMDD_HHMMSS_Q.json    ← Qualifying
- YYMMDD_HHMMSS_Q2.json   ← Qualifying 2

Examples:
- 260109_150000_FP.json
- 260109_180000_Q.json

These files are NOT used for Live Series Standings.
They ARE used for Track Records (Global Rankings).
