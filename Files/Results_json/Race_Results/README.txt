# Race Results Only

This folder should contain ONLY actual race result files.

File naming pattern: `YYMMDD_HHMMSS_R.json` or `YYMMDD_HHMMSS_R2.json`

Examples:
- 260109_192827_R.json  ← Race 1
- 260109_203045_R2.json ← Race 2

These files are used to calculate the Live Series Standings.

DO NOT put practice or qualifying files here!
